Check names are set in Anybody and fitted to one column width with the font's own width axis; the one asking check (Blood) is heavy and carries the only alert colour, a filled amber disc. Layer two is the drape turned over: a bone panel over the words, the window stays open.

Previews: `#/proto/D/tracktrace`, `bubblegrade`, `veinsqueeze`, `braindrift`, `garnmeter`.
3. **SpikeCount is real, and the press answers at once.** Laptop: entering the check loads and warms both models (the corner tag reads "Loading model", then LIVE). Pressed before the models are warm: the stored outlines start in under 0.1 s (tag REPLAY) and the live result takes their place when it lands (tag LIVE). Phone or any failure: stored result, tag REPLAY. The % counts spiky / drawn so far and lands on 58.5% of 53, then "5.2% before flight" and "Crew medic: run the blood tests for red-cell breakdown." from `act()`.
